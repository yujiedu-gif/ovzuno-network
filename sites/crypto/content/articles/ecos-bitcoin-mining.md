## How Bitcoin mining supports proof of work

In Bitcoin, mining is the process of constructing and proposing candidate blocks that meet Bitcoin’s proof-of-work condition. Mining software builds a candidate block and block header from transactions, then sends header work to hashing hardware. This describes Bitcoin’s mechanism, not a universal process for every cryptocurrency network.

The proof-of-work condition is part of how Bitcoin organizes proposed blocks. Mining software and hardware perform the block-construction and hashing work; the network’s nodes remain responsible for checking whether a proposed block follows the applicable rules. Producing a candidate does not, by itself, establish that the block is valid or that the network will accept it.

Independent validation is conceptually distinct from mining. Full nodes check block and transaction rule compliance. A miner may also operate a validating node, but those are separate functions: a description of mining work should not be read as proof that the miner or a service provider independently validates all network rules.

That separation is central to understanding the phrase “ECOS Bitcoin mining.” It connects a provider-associated label to the Bitcoin network’s mining process, but it does not make the provider part of Bitcoin’s protocol or establish how the provider performs any work. Bitcoin protocol behavior and a particular service’s organization are different subjects.
