An NFT, or non-fungible token, is a blockchain token with an individually identifiable record rather than a unit designed to be interchangeable one-for-one with other units. That identity distinguishes it from a fungible crypto token, but it does not by itself establish that referenced content is authentic, scarce, valuable, or legally owned by the token holder.

## What does “NFT” mean?

“ NFT” stands for “non-fungible token.” Fungibility describes whether units can be exchanged as equivalent units of the same type. A non-fungible token instead has an identity that distinguishes it from other tokens within its own system.

For example, the ERC-721 standard identifies an NFT through the combination of its smart-contract address and token ID on an Ethereum chain. The contract address identifies the token contract, while the token ID identifies a token within that contract. The name or image associated with a token is not a global identifier. This is one standard’s model, not a rule that every NFT must use ERC-721. [source](<https://eips.ethereum.org/EIPS/eip-721>)

An NFT is the token record, not necessarily the image, audio, document, collectible, or other material it may refer to. An optional ERC-721 metadata interface can expose a token URI that refers to metadata for that token ID. The URI and referenced material may be stored on-chain, use content-addressed storage, or depend on mutable off-chain hosting. The token standard alone does not guarantee that referenced content will remain available or unchanged. [source](<https://eips.ethereum.org/EIPS/eip-721>)

## How an NFT differs from a fungible token

A fungible token is designed so that units of the same type are interchangeable. ERC-20, for example, defines a common interface for token balances, direct transfers, and approvals that let another address spend up to an authorized amount. The interface describes how applications interact with a token; it does not determine the token’s backing, issuance policy, market value, compliance, or implementation safety. [source](<https://eips.ethereum.org/EIPS/eip-20>)

With an NFT, the relevant identity is tied to a particular token rather than only to a balance of equivalent units. A balance may indicate how many units of a fungible token an address holds; an NFT’s contract-and-ID pair distinguishes the specific token record. This difference concerns identification and interchangeability. It does not, by itself, prove that an NFT is rare, that its associated content is genuine, or that it has any particular value.

Other behaviors are matters of design and implementation. The term “NFT” alone does not establish whether a token can be divided, how transfers are controlled, or what an application permits. Nor does it mean every NFT is unique in every respect: distinct token identities do not necessarily imply distinct referenced content or exclusive rights.

## What an NFT can represent—and what it does not guarantee

An NFT may be used as a token record associated with digital content or another subject. But the token’s on-chain identity and the thing it refers to are separate. A metadata reference can point to material stored outside the blockchain, and the standard does not guarantee that the material is permanent, accurate, available, or licensed to the holder. [source](<https://eips.ethereum.org/EIPS/eip-721>)

Holding or transferring a token therefore does not automatically transfer copyright, physical title, a license, or every other right connected with referenced content. Token ownership is an on-chain record under a contract’s rules; the relationship between that record and off-chain material or rights depends on additional systems and terms. The token label alone cannot settle that relationship.

The same distinction applies to claims of authenticity or exclusivity. A token can be identified by its contract and token ID, but that identification does not independently establish who created the referenced work, whether the creator had authority to associate it with the token, or whether another copy exists elsewhere. Those claims require evidence beyond the definition of an NFT.

## What to check when interpreting an NFT claim

When a description makes a claim about an NFT, separate the token record from the claim about its subject:

- **Identify the token.** Where the information is available, use the relevant network, contract address, and token ID rather than relying only on a name, symbol, or image. For ERC-721, the contract-and-ID combination identifies the token on an Ethereum chain. [source](<https://eips.ethereum.org/EIPS/eip-721>)
- **Inspect what the metadata points to.** Determine what the token URI references and whether the material is stored on-chain, content-addressed, or hosted elsewhere. A URI is a reference, not a guarantee of permanence or availability. [source](<https://eips.ethereum.org/EIPS/eip-721>)
- **Separate technical statements from rights claims.** A statement about a token’s transfer or identification is different from a statement that a holder owns, may reproduce, or has a license to use the referenced material. Look for the specific terms or authoritative documentation supporting the latter.
- **Treat the implementation as relevant.** A token standard defines particular interfaces or behaviors; it does not establish every property of a specific contract, application, or associated item. [source](<https://eips.ethereum.org/EIPS/eip-20>)

These checks help clarify what a description actually asserts. They are not a recommendation to acquire, sell, or use any particular token.

## Where the definition stops

“NFT” is a technical label for a non-fungible token, not a universal answer to questions about legal rights, tax, regulation, or compliance. Those questions require evidence specific to the jurisdiction, facts, and time involved; this definition makes no legal or tax conclusion. Nor does the label alone establish security, recovery options, fees, yield, or long-term availability.

The useful distinction is narrow: a fungible token uses interchangeable units of the same type, while an NFT has an individually identifiable token record. What that record represents—and what rights, content, or guarantees accompany it—must be assessed separately.
