## What Pi Network means by “mining”

A project’s use of “mining” does not, by itself, define what the activity does technically. In Bitcoin, proof-of-work mining involves varying a nonce in a block header until its hash satisfies the network’s target condition. It is a computational search tied to Bitcoin’s block rules. [source](<https://bitcoin.org/bitcoin.pdf>) That example gives the term a concrete meaning in one network; it does not make every project-described “mining” activity the same process.

For Pi specifically, the permitted evidence does not include current official documentation explaining the project’s use of the term. It does not establish what an app action records, whether it contributes to a network role, or how any related token accounting works. Those are different questions, and the available evidence cannot answer them.

It is also important to distinguish activity visible to a user from protocol work performed by network software. A user might interact with an app while other components handle transaction checks or block production, but no Pi-specific division of responsibilities can be confirmed here. In Bitcoin, for example, a full node generally relays a received transaction after independently checking it against applicable validity and relay-policy rules. [source](<https://developer.bitcoin.org/devguide/p2p_network.html>) That is a specific Bitcoin function, not evidence about Pi’s app or participants.

Accordingly, readers should interpret “mining” in Pi descriptions as project terminology unless documentation explains the associated technical action. The word alone cannot demonstrate that a phone performs proof-of-work hashing, validates transactions, or produces blocks.
