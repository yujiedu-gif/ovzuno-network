## How blockchain functions can fit into games

In a gaming context, blockchain infrastructure may be used for selected records or transactions. A game might combine such a component with a user interface and other services. For example, an Ethereum decentralized application combines a smart contract running on a decentralized network with a frontend interface, while hosting, key management, indexing, and other supporting services can still introduce centralized dependencies. This is an architectural example, not evidence that Forte or a particular game uses that design.

The distinction between on-chain and off-chain components helps clarify what a blockchain connection does—and does not—mean. On-chain activity is handled through the blockchain’s state and rules. Off-chain components operate outside that state. A game could therefore use a blockchain for some activity without placing all gameplay rules, user-facing features, or supporting services on the blockchain. Which functions are recorded, and which remain elsewhere, depends on the implementation.
