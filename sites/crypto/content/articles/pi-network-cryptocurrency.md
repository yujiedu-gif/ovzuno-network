## How Pi Network differs from proof-of-work mining

Proof of work, or PoW, is a computational mechanism in which a participant searches for a result that satisfies a network target. In Bitcoin, mining software constructs candidate-block and header work, and the search varies a nonce until the resulting hash is at or below the current target. This defines a specific computational task; it does not establish that every system called a blockchain or mining works the same way. [source](<https://bitcoin.org/bitcoin.pdf>)

The distinction is not simply whether someone uses a phone or computer. The relevant question is whether the protocol requires repeated hash computation to find a qualifying result, and how that work relates to proposing blocks and establishing history. The available claims explain Bitcoin’s mechanism but do not show that Pi uses it. Phone activity, by itself, is not evidence of Bitcoin-style proof-of-work hashing.

Block construction and validation are also separate functions in the Bitcoin example. Mining software prepares candidate work, while a full node generally relays a received transaction only after independently checking that it meets applicable validity and relay-policy rules. These checks illustrate that computational work and rule validation are not interchangeable: work does not itself demonstrate that a proposed transaction or block follows all network rules. This is a Bitcoin-specific comparison and should not be transferred to Pi without Pi-specific technical evidence. [source](<https://developer.bitcoin.org/devguide/p2p_network.html>)

A further technical distinction is the relationship between mining software and hardware. In Bitcoin, software transforms block-template information into header work for hashing hardware to search. That description identifies the mechanism to look for in a PoW system; it does not establish that a phone app performs the same operations, or that Pi uses this architecture.
