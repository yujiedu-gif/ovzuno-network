## How to verify an EarnX reference

A page that repeats a name does not, by itself, demonstrate that it is authoritative or that it describes the same entity as another page.

If the reference claims there is a token, look for documentation that explicitly connects the token name to a particular network and contract address. A contract address is an identifier for a deployed program or token contract on a particular network; names alone are not enough to match contracts. Compare the documented network and address with the corresponding network’s explorer records. Treat the comparison as an identity check, not as proof of the project’s broader claims.

Keep the identifiers together when comparing references: the project or service name, the network, and the contract address, if a token is involved.
