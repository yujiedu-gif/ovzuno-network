The fee that applies depends on the transaction flow and the network, so check the wallet’s current confirmation details and separate any displayed charges before deciding whether to proceed.

## Which NFT actions can require a network transaction

Buying, selling, listing, minting, and transferring describe different NFT-related actions. They should not be assumed to use the same transaction steps or incur the same network cost. The evidence available here does not verify which of these actions, in a current Rarible flow, requires an on-chain transaction or whether a particular step happens immediately on-chain. ## How to check the fee before confirming

Use the confirmation step to verify the proposed transaction rather than relying on a generic estimate or an earlier screen:

1. **Identify the action.** Read the marketplace flow and wallet prompt to determine whether the proposed step concerns buying, selling, listing, minting, transferring, or another operation. Do not assume the label alone proves what the wallet is being asked to authorize.
2. **Confirm the network.** Check the network displayed for the proposed transaction. Use the documentation for that network; do not apply an estimate or explanation for a different network.
3. **Separate displayed amounts.** Look for the network fee and distinguish it from any marketplace, payment, or other charge that is separately identified. If a label is unclear, do not guess what it includes.
4. **Review the current confirmation details.** Before confirming, read the amount, asset, network, and transaction description shown by the wallet. Check that these match the intended action and the marketplace flow.
5. **Consult current official materials if needed.** Use Rarible’s current official documentation for applicable marketplace terms, and the relevant wallet and network documentation for fee presentation and transaction mechanics. If the details remain unclear, pause rather than treating an estimate as a known cost.
