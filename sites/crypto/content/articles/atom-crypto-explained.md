## What does ATOM mean in crypto?

ATOM refers to a crypto asset associated with the Cosmos Hub. The Hub is a network; ATOM is an asset. The wider Cosmos ecosystem is a broader category and should not be treated as another name for either one.

A useful point of context is the Cosmos SDK, a modular framework for building customized, application-specific blockchains from reusable and custom application modules. The SDK is software for constructing blockchains; it is not ATOM, and its general description does not specify the Cosmos Hub’s particular functions. [source](<https://docs.cosmos.network/v0.47>)

Keeping these categories separate helps avoid a common mistake: evidence about a framework does not automatically establish the rules of a particular network or the role of a particular asset. The available evidence does not show that ATOM is required for every network or activity associated with Cosmos.

## How ATOM relates to the Cosmos Hub

ATOM is associated with the Cosmos Hub, but that relationship does not make the token and network synonymous. The Hub is the specific protocol context named in this association. The wider Cosmos ecosystem can include separate application-specific blockchains, and the Cosmos SDK’s modularity describes a way to build such chains—not a universal relationship among their assets, operation, or security. [source](<https://docs.cosmos.network/v0.47>) [source](<https://docs.cosmos.network/v0.47>)

In particular, reusable software modules do not prove that every blockchain built with the SDK depends on ATOM. Nor does modular application software by itself establish that a network separates execution, consensus, settlement, and data availability into different security layers. Those are separate architectural questions requiring evidence about the specific network. [source](<https://docs.cosmos.network/v0.47>) [source](<https://docs.cosmos.network/v0.47>)

This boundary is important when reading descriptions that use “Cosmos” loosely. A statement about the ecosystem, a software framework, or an individual blockchain should not be silently converted into a claim about the Cosmos Hub or ATOM. The available evidence supports describing the SDK as a framework, but does not establish a universal ATOM requirement across Cosmos-related activity. [source](<https://docs.cosmos.network/v0.47>)

ATOM’s association with the Cosmos Hub does not, on the evidence available here, establish ownership of the Hub, a company, or projects in the wider ecosystem.
