## How mining hardware fits into proof-of-work

Mining hardware performs computations used in a proof-of-work process, but it does not set the network’s rules. Hardware is one component in a broader arrangement involving mining software and network software. Software prepares or coordinates work; hashing hardware carries out computations; and network participants apply the network’s rules when evaluating proposed blocks. These roles should not be collapsed into a single claim that a device “controls” or “creates” a cryptocurrency network.

Bitcoin illustrates the separation. When histories compete, Bitcoin nodes select the valid chain representing the greatest cumulative proof of work. A miner’s computational contribution can help produce a candidate block, but the chain-selection rule and validity checks belong to the network protocol and its participants, not to the equipment manufacturer. [source](<https://bitcoin.org/bitcoin.pdf>)
