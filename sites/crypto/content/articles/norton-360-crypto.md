## How a mining feature would relate to proof-of-work

Proof of work is a consensus model in which a publishing participant is selected through a computational problem that is difficult to solve but straightforward for other nodes to verify. It consumes time, energy, and computational cycles. This is a general description, not a claim about Norton 360 or every cryptocurrency network. [source](<https://csrc.nist.gov/glossary/term/Proof_of_work_consensus_model>)

For Bitcoin specifically, mining software can construct a candidate block and block header from transactions and send header work to hashing hardware. This describes a possible device-side workflow; it does not show that Norton 360 performs it. [source](<https://developer.bitcoin.org/devguide/mining.html>)

A candidate block is a proposal, not an automatic network decision. In Bitcoin’s design, when histories compete, nodes select the valid chain representing the greatest cumulative proof of work. Nodes still apply validity rules: computational work does not make an invalid block valid. [source](<https://bitcoin.org/bitcoin.pdf>)

This distinction separates three stages of the example. Mining software prepares candidate work; hardware searches for a result meeting the relevant work condition; and network nodes independently apply validity and chain-selection rules. The product or application involved in one stage should not be described as controlling the others unless documentation establishes that role. The Bitcoin workflow is an illustration of Bitcoin’s design, not a universal specification for all proof-of-work networks.

So, if an application were documented as coordinating mining, that fact alone would not mean it determines consensus. It would describe a role in the work process; the network’s participants and rules govern whether a proposed block is accepted and which valid history is followed. For Norton 360 specifically, the allowed evidence does not verify a mining component, so no connection between the product and Bitcoin mining—or another network’s consensus process—can be asserted.
