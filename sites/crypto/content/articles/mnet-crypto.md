## What the documentation says about consensus

Consensus is the set of rules and processes by which a network’s participants validate proposed records and coordinate on accepted history. Proof of work is one possible design, not a synonym for cryptocurrency. In the general model described by NIST, proof of work selects a publishing node through a computational problem that is hard to solve but straightforward for other nodes to verify. That definition explains a mechanism category; it does not identify which category any particular project uses. [source](<https://nvlpubs.nist.gov/nistpubs/ir/2018/nist.ir.8202.pdf>)

A project’s technical documentation would need to establish the relevant mechanism before the label “mining” could be applied. For a proof-of-work claim, readers would look for an explicit description of computational work in the network’s block-production and validation process, along with how other participants verify proposed work. If the documentation describes a different method, the mechanism should be described according to those documented rules rather than called mining by assumption.
