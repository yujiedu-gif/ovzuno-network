The distinction between a token and a protocol is useful when checking claims. A token is an asset represented and handled under rules implemented for a particular system; a protocol is the set of rules or components that describes how a system operates. A name alone does not show which category a reference belongs to. Nor does a project description, by itself, establish that the described system is operating as stated.
