# OvZuno Crypto content program

OvZuno Crypto owns the entity **crypto payment infrastructure**. The publication covers payment and merchant infrastructure, stablecoins and settlement, wallets and custody, payment-related blockchain foundations, security and compliance operations, crypto cards, cross-chain interoperability, and PayFi or agentic payments.

The private production repository is `yujiedu-gif/ovzuno-content-pipeline`. It owns keyword research, prompts, source packs, Batch state, validation, and cost records. This public repository receives only articles that have passed editorial, evidence, duplicate, and site-build gates.

The rollout gates are 50, 250, 1,000, and 10,000. Candidate keywords do not become articles until DataForSEO demand and SERP intent, unique topic ownership, evidence availability, and semantic duplicate checks pass.

The publication stays prelaunch and `noindex` until the existing launch checklist is complete. Generated dates are prohibited. Publication code writes the real release date; `lastmod` is emitted only after a verified substantive change.

At launch, the Crypto host will use a sitemap index with pages, topics, and article sitemaps split at approximately 2,000 article URLs. Only canonical, indexable, published pages are included.
